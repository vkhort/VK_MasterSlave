# ⚙️ VK_MasterSlave: Распределенная система дозирования и смешивания (ESP32 + ESP32-C3)

Проект представляет собой архитектуру распределенной автоматизированной системы для многокомпонентного взвешивания, дозирования и смешивания различных составов. 

Система построена на беспроводном Wi-Fi взаимодействии центрального пульта управления (**Master Hub на базе ESP-32S**) и сети удаленных автономных исполнительных модулей (**Slave Nodes на базе ESP32-C3-SuperMini**).

## 🚀 Ключевые архитектурные особенности

- **Асинхронность и многозадачность (Non-blocking):** Все исполнительные алгоритмы (генерация шагов двигателя для A4988, плавное перемещение вала сервоприводов, опрос датчиков) реализованы на неблокирующих таймерах по принципу `millis()` / `micros()`. Цикл `loop()` полностью разгружен, что обеспечивает мгновенный отклик сетевого стека веб-сервера.
- **Прямая IP-адресация (Zero-mDNS):** Для исключения скрытых таймаутов, микро-фризов ядра и задержек при передаче пакетов, протокол mDNS полностью отключен. Подчиненные модули считывают свои жестко фиксированные статические IP-адреса из локальной файловой системы и запрашивают их у Точки Доступа Хаба на этапе сетевого рукопожатия.
- **REST API Перенаправление (HTTP Forwarding):** Веб-интерфейс Мастера взаимодействует с пользователем через быстрые AJAX/Fetch запросы. Хаб перехватывает клики пульта управления и выполняет прозрачную высокоскоростную трансляцию HTTP GET пакетов исполнительным модулям.
- **Энергонезависимая конфигурация (LittleFS):** Все критические параметры устройств (SSID, пароли, пины подключения, рабочие скорости, ускорения, калибровочные константы) хранятся в файлах `config.txt` на Flash-памяти плат и могут настраиваться индивидуально через веб-панель без необходимости перепрошивки контроллеров.

## 📁 Структура репозитория (Монорепозиторий)

- `/VK_ESP32S_center` — **Центральный пульт управления (Master Hub)** на ESP-32S. Поднимает собственную защищенную Wi-Fi сеть `VK_MASTER_HUB`, отслеживает динамическое подключение IP-адресов исполнителей в реальном времени, координирует общий цикл автоматизации и управляет индикацией готовности комплекса.
- `/VK_ESP32C3supermini` — **Исполнительный модуль подачи (Slave Node)** на ESP32-C3-SuperMini. Принимает REST-команды от Хаба, управляет шаговым двигателем подачи компонента через драйвер A4988 и силовым сервоприводом заслонки бункера через аппаратный ШИМ (`LEDC` API версии 3.x).

## 🛠️ Аппаратный состав комплекса

1. **Центральный узел (Master):**
   * Микроконтроллер ESP-32S (NodeMCU / DOIT DevKit).
   * Датчик Холла (концевик для точного позиционирования карусели в нулевую точку).
   * Тензодатчик весовой платформы с аналоговым цифровым усилителем **HX711**.
   * Силовой шаговый двигатель финального миксера/смесителя.
   * Светодиод-индикатор готовности распределенной сети (GPIO2).

2. **Исполнительные узлы (Slave Nodes — до 4-х штук в системе):**
   * Микроконтроллер ESP32-C3-SuperMini.
   * Драйвер шагового двигателя **A4988** (или DRV8825).
   * Шаговый двигатель подачи материала (например, NEMA 8 или NEMA 17).
   * Силовой сервопривод заслонки бункера (например, мощный металлический **MG996R** или микро-серво SG90).

## ⚡ Критически важное требование к питанию!

> **ВНИМАНИЕ:** Одновременное использование Wi-Fi радиомодуля (пики до 400мА) совместно с пусковыми токами шаговых двигателей и мощных сервоприводов (до 2.5А на один сервопривод MG996R при блокировке вала) **категорически требует разделения линий питания**!
> 
> Встроенные линейные регуляторы плат ESP32 не рассчитаны на такие нагрузки. Силовая часть драйверов моторов (`VMOT`) и линии питания сервоприводов `+5V / +6V` должны быть подключены к мощным внешним источникам или ЛБП. Минусовые провода (**GND**) всех блоков питания и плат ESP32 должны быть надежно соединены в одной точке.

## 📈 Планируемый алгоритм автоматизации (Класс `VK_ESP32_center`)

В рамках развития проекта ведется интеграция единого класса автоматизации, который будет циклически выполнять следующий сценарий:
1. **Вывод в ноль (Home):** При включении Мастер медленно вращает платформу, пока не сработает *датчик Холла*, фиксируя стартовую позицию системы.
2. **Цикл дозирования (4 компонента):**
   * Мастер шлет Wi-Fi команду на открытие заслонки и включение подачи первому модулю `Slave 1` (`192.168.4.2`).
   * В фоновом режиме Мастер непрерывно считывает показания веса с тензодатчика **HX711**.
   * При достижении целевого веса первого компонента Мастер отправляет экстренную Wi-Fi команду «STOP» на закрытие бункера.
   * Мастер поворачивает карусель на 90 градусов и аналогично запрашивает подачу у `Slave 2`, `Slave 3` и `Slave 4`.
3. **Финал:** По окончании сбора всех 4-х компонентов Мастер включает силовой двигатель миксера для перемешивания готового состава.
